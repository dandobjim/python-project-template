# Architecture Decision Records — template repository

Decisions about the **template itself** (which tooling and conventions every generated project inherits). Decisions about a specific generated project belong in that project's own `docs/adr/`.

ADRs use [MADR 4](https://adr.github.io/madr/); start from [`template/docs/adr/0000-template.md`](../../template/docs/adr/0000-template.md).

| ADR | Title | Status |
| --- | ----- | ------ |
| [0001](0001-use-uv-and-ruff-for-tooling.md) | Use uv, Ruff and mypy as the default tooling of generated projects | accepted |
| [0002](0002-offer-pyrefly-as-optional-type-checker.md) | Offer pyrefly as an optional type checker | accepted |
